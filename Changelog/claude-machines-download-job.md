# Download machines works for thousands of companies

Download machines on the Companies page no longer stops with "Execution Timeout Expired" for long lists. The file is now
built in the background, reading Advance a few hundred companies at a time: the button shows how far it is ("Reading
machines… 40%"), you can keep working or leave the page, and the file saves when it is ready. If you come back to the
Companies page before it saved, click "Save machines file" (it is kept two hours).

If Advance does not answer in time for some companies, the file still comes, and those companies are marked "Advance
did not answer in time" on the Companies sheet.
