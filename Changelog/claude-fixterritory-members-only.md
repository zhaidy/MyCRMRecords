# Projects that have ended never takes away the CSST part's temporary territories

The scheduled task *Projects that have ended* took away temporary territories that no project member has (the CSST
part's), which MyCRM's own timer leaves alone: on 30 October it switched off 30,957 of them, all switched back on the
same day. It now only takes away the temporary territories of project members whose project is over, and Roll back
switches back on everything it switched off that day except those.
