# Company summary quick again; machines are their own download

The Company summary (Download on the Companies page) is back to what it was before the last update, so it is quick
again for thousands of companies. The companies' machines are now a separate download, Download machines, with the
same search and filters: a Companies sheet with each company's machine counts and a Machines sheet with every machine.

Download machines reads Advance for every company in the list, so a long list takes several minutes; search or filter
first for a quicker file. The machine queries are also faster than in the last update.
