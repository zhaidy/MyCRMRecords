# Costing sheets and request forms are in MyCRMRecords now

MyOrders' costing sheets and request forms, which were in MyOrdersRecords, are now in MyCRMRecords: Costing sheets and Request forms in the menu, with the same lists, pages, downloads and prints, read only. You see the ones MyOrders let you see.

A costing sheet's or request form's company opens the company's page, and a company's page lists its newest costing sheets and request forms, with See all for the whole list of that company's.
