# Projects open faster; text easier to read

- The Projects list opens quickly however many projects there are: it now reads only the 50 projects shown (their
  companies, members and names), where before it read every project's before showing the first page. A project's page
  reads the names of its people at once instead of one by one.
- The text is set in the Inter font (kept by MyCRMRecords itself), with darker grey text and figures that line up in
  columns, as Windows' own font was hard to read.
